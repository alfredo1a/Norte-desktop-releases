# Norte Desktop — versões publicadas

Este repositório guarda **somente os pacotes do programa** Norte Desktop, usados pela
atualização automática do aplicativo.

- Não contém código-fonte.
- Não contém dados financeiros, credenciais, configurações, históricos ou logs.

Cada versão é uma *release* com dois arquivos:

- `ControleFinanceiroV3.zip` — o programa;
- `versao.json` — número da versão, notas e o SHA-256 do pacote.
